A tiny Node program that writes one short text to `/output/entry.txt`: a
lighthouse log with one unexplained line, no boat, no footprints, and a
small blue shell still wet in the margin, written to intrigue the AI
judge reading it. Built for make.fun's
[Make the AI judge feel curious](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311)
bounty, where an AI judge compares entries two at a time against a
published curiosity brief.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt` (UTF-8, under 280
characters).
